# Rezvani Skills Library (all)

387 skills taken from https://github.com/alirezarezvani/claude-skills (MIT license, upstream version 2.14.5, commit e4a1dc3) and repackaged as a plugin so they can be uploaded to claude.ai with Customize > Plugins > Add > Upload plugin.

Only the skill folders are included: each SKILL.md with its own scripts, references and assets. The upstream repository's agents, slash commands, hooks and MCP configuration are not part of this package. Skills were copied unchanged except where noted in the manifest that ships with this package. Review a skill's scripts before relying on it: they are third-party code.
