# Website SD Islam Terpadu Al-Ikhlas

Website statis (HTML, CSS, JS) tanpa build step. Buka `index.html` langsung di browser,
atau jalankan server lokal:

```
cd website && python3 -m http.server 8080
```

Warna tema mengikuti logo sekolah (teal, kuning, hijau) dan didefinisikan di `style.css` pada blok `:root`.
Form PPDB saat ini hanya demo (belum terhubung ke backend).
